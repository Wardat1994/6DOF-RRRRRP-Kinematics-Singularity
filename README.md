# 6-DOF RRRRRP Robot – Kinematics & Singularity Analysis

A research-oriented implementation of the kinematic modeling, workspace analysis, Jacobian computation, and singularity analysis of a **6-DOF RRRRRP serial robotic manipulator**.

The manipulator consists of **five revolute joints** followed by **one prismatic joint**:

\[
q =
[\theta_1,\theta_2,\theta_3,\theta_4,\theta_5,d_6]^T
\]

The project is currently implemented in **Python** and is structured for further validation and extension using MATLAB.

## Denavit–Hartenberg Model

The manipulator is modeled using the standard Denavit–Hartenberg convention.

| Joint | \(a_i\) | \(\alpha_i\) | \(d_i\) | \(\theta_i\) | Type |
|---|---:|---:|---:|---:|---|
| 1 | 0 | \(\pi/2\) | \(H\) | \(\theta_1\) | Revolute |
| 2 | \(a_2\) | 0 | 0 | \(\theta_2\) | Revolute |
| 3 | \(a_3\) | 0 | 0 | \(\theta_3\) | Revolute |
| 4 | \(a_4\) | 0 | 0 | \(\theta_4\) | Revolute |
| 5 | 0 | \(-\pi/2\) | 0 | \(\theta_5\) | Revolute |
| 6 | 0 | 0 | \(d_6\) | 0 | Prismatic |

The complete forward transformation is:

\[
{}^{0}T_{6}
=
{}^{0}T_{1}
{}^{1}T_{2}
{}^{2}T_{3}
{}^{3}T_{4}
{}^{4}T_{5}
{}^{5}T_{6}
\]

---

## Forward Kinematics

The forward kinematic model calculates the complete end-effector pose:

\[
{}^{0}T_{6}
=
\begin{bmatrix}
R_0^6 & p_e \\
0 & 1
\end{bmatrix}
\]

where:

\[
p_e =
\begin{bmatrix}
x\\
y\\
z
\end{bmatrix}
\]

represents the Cartesian position of the end-effector and \(R_0^6\) represents its orientation.

The implementation also extracts the positions of all robot joints for visualization and subsequent Jacobian calculations.

## Jacobian Analysis

Two Jacobian representations are implemented.

### Translational Jacobian

\[
J_v \in \mathbb{R}^{3\times6}
\]

relates joint velocities to end-effector linear velocity:

\[
v_e = J_v(q)\dot q
\]

For revolute joints:

\[
J_{v_i}
=
z_{i-1}\times(o_6-o_{i-1})
\]

For the sixth prismatic joint:

\[
J_{v_6}=z_5
\]

### Full Geometric Jacobian

The complete geometric Jacobian is:

\[
J_g =
\begin{bmatrix}
J_v\\
J_\omega
\end{bmatrix}
\in \mathbb{R}^{6\times6}
\]

and relates joint velocities to the complete end-effector twist:

\[
\begin{bmatrix}
v_e\\
\omega_e
\end{bmatrix}
=
J_g(q)\dot q
\]

## Singularity Analysis

Singular configurations are investigated using several complementary numerical indicators.

### Jacobian Rank

A full geometric singularity occurs when:

\[
\operatorname{rank}(J_g)<6
\]

### Determinant

For the square geometric Jacobian:

\[
\det(J_g)=0
\]

at an ideal singular configuration.

### Singular Value Decomposition

The Jacobian is decomposed as:

\[
J_g = U\Sigma V^T
\]

The minimum singular value,

\[
\sigma_{\min}
\]

is used as an important indicator of proximity to singularity.

### Condition Number

\[
\kappa(J_g)
=
\frac{\sigma_{\max}}{\sigma_{\min}}
\]

A large condition number indicates poor numerical conditioning and proximity to a singular configuration.

## Translational Manipulability

For the translational Jacobian:

\[
w(q)
=
\sqrt{\det(J_vJ_v^T)}
\]

which is equivalently related to the product of the translational Jacobian singular values.

![Manipulability](results/manipulability_vs_theta3.png)

Low manipulability indicates reduced Cartesian dexterity and may indicate proximity to a translational singularity.
